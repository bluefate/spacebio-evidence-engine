# Code of Conduct

## Purpose
Set expectations for respectful collaboration.

## Scope
Applies to repository discussions, issues, pull requests, reviews, and project communication.

## Current status
Initial lightweight code of conduct. The team may replace it with the Contributor Covenant if public community participation begins.

## Expectations
- Be respectful, specific, and constructive.
- Critique ideas and implementation, not people.
- Preserve scientific uncertainty and avoid overstated claims.
- Welcome contributors with different levels of software and science experience.
- Escalate repeated harmful behavior to maintainers.
