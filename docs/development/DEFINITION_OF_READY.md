# Definition of Ready

## Purpose
Define when work is ready to start.

## Scope
Issues, tasks, and agent assignments.

## Current status
Initial readiness checklist.

## Ready checklist
- User value or technical goal is clear.
- Scope is small enough for one PR.
- Acceptance criteria are written.
- Relevant docs are linked.
- Data, security, and citation risks are identified.
- Human decisions are resolved or explicitly deferred.
