# Deployment

## Purpose
Define deployment expectations beyond local development.

## Scope
MVP local deployment and future hosted deployment.

## Current status
Initial deployment guidance.

## MVP
Docker Compose is sufficient for the August MVP (deadline 2026-08-31) local demonstration and development. Public hosting is deferred post-August.

## Future
Hosted deployment should include managed secrets, managed database backups, HTTPS, dependency scanning, logs, and environment separation.
