# Local Setup

## Purpose
Define the expected local development environment.

## Scope
Pre-implementation setup targets for backend, frontend, database, and notebooks.

## Current status
Initial setup guide. Exact commands will be added after scaffolding.

## Expected tools
- Python 3.12 or newer.
- Node.js compatible with selected Next.js version.
- Docker and Docker Compose.
- PostgreSQL client tools.
- Jupyter.

## Expected local services
- PostgreSQL with pgvector.
- FastAPI backend.
- Next.js frontend.
- Optional worker process for ingestion and evaluation.
