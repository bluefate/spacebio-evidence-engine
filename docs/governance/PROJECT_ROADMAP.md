# Project Roadmap

## Purpose
Define incremental delivery phases.

## Scope
August MVP through future phases.

## Current status
Milestone dates approved for compressed August MVP (deadline **2026-08-31**). See [decision log](DECISION_LOG.md).

## August MVP phases (2026-08-04 through 2026-08-31)
1. Documentation and architecture decisions locked.
2. Repository scaffolding and local Compose services.
3. Corpus manifest (~10–15 OA papers) and ingestion pipeline (CLI).
4. Chunking, embeddings, and vector retrieval.
5. Grounded Q&A with passage citations + insufficient-evidence path.
6. Minimal citation-first UI, smoke tests, and draft eval questions.
7. August MVP demo readiness (local).

## Post-August phases
8. Study comparison and richer metadata inspection.
9. Evaluation hardening and optional public deploy.
10. Future graph phase with optional Neo4j.
11. Future contradiction, gap, and curator workflows.

## Owners
Repository owner for approvals and merges. Agents implement single issues within backlog rules.
