# Release Process

## Purpose
Define how releases are prepared and approved.

## Scope
MVP and future releases.

## Current status
Initial process.

## Process
- Confirm all milestone issues are complete.
- Run automated tests, linting, type checks, and migrations.
- Run RAG evaluation benchmark.
- Review citation and insufficiency behavior.
- Update documentation and release notes.
- Tag release after human approval.
